# GLOSSARY (agent adds terms in plain words)
Format: **Term**: plain meaning. Example from this project.

- **Virtual Environment**: An isolated Python installation folder dedicated to a single project, keeping its libraries separate from the rest of your computer. Example: `.venv` created with Python 3.11 for `gharchive-lakehouse`.
- **Rate Limit**: The maximum rate of requests or tokens an API allows before temporarily blocking further calls (returning HTTP 429). Example: Google AI Studio capping Gemini Flash at 15 Requests Per Minute (RPM) and 1,500 Requests Per Day (RPD).
- **.gitignore**: A configuration file telling Git which files and directories should never be tracked or uploaded to GitHub. Example: ignoring `.env` (protecting your secret API keys) and `data/` (preventing multi-gigabyte raw files from polluting git history).
- **actor**: The GitHub user account that triggered the event (contains `login`, `id`, avatar URL). Example: `Boris-Sachet` opening an issue.
- **repo**: The GitHub repository on which the event took place (contains `name` and `id`). Example: `knowmics-lab/oncoreport`.
- **payload**: The inner details payload specific to each event type; for an issue event, it holds the `action` (`opened`, `closed`, `reopened`), `issue` number, title, body, and labels.
- **created_at**: The UTC timestamp in ISO-8601 string format indicating when GitHub recorded the event. Example: `2024-06-10T15:00:00Z`.
- **Ground Truth**: Real, observed, trustworthy target data directly from the source used to train and evaluate models. Example: Real issue labels (`bug`, `enhancement`) added by project authors on GitHub.
- **Silver Labels**: Labels automatically inferred or generated by an external AI model (e.g. Gemini) rather than verified ground truth.
- **Manifest**: An audit log / inventory catalog that lists all downloaded or ingested files, their byte sizes, and processing statuses. Example: `data/raw/manifest.json`.
- **Stream Truncation**: When a network stream cuts off mid-transfer before sending the complete file or EOF marker. In gzip, this produces an incomplete file that crashes standard unzippers unless explicitly validated.
